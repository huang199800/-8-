# 快乐8选号机

面向 Windows 的福利彩票快乐8数据分析与自动研究桌面软件。当前发布版本 **v0.6.0-preview**。本仓库仅分发便携包和使用文档，不提供源码。

> 历史拟合匹配不代表下一期预测优势。当前真实历史复测仍未发现稳定优势，软件不保证中奖或收益。

## 下载与启动

前往 [Releases 下载页面](https://github.com/huang199800/-8-/releases) 获取 Windows x64 便携包。解压整个压缩包后运行 `快乐8选号机.exe`，请保留同目录运行依赖，不能只复制EXE。首次使用需要联网完成有效授权。收费功能根据授权状态开放。

本版在 Windows 11 22631、Ryzen 5 3600、32GB内存、AMD RX580 环境实际运行；干净 Windows 10 尚未验收，不承诺已完成兼容验证。

## 0.6四项研究升级

### 1. 真实滞后特征与消融

提供原5特征、多窗口趋势、遗漏分布、状态与共现、全部新特征五套输入，全量18维。特征使用计算截止期以前的数据，包括多窗口频率差、波动、连出、遗漏间隔、遗漏分位、支持度、收缩后的条件复出与共现。新特征已接入真实训练和推断；可比较不同特征组及训练窗口。它们是研究变量，尚未证明具有预测优势。

### 2. 停滞后切换研究方向

新建研究可设置开发指标停滞阈值，默认72次。连续没有改进后轮换参数优化、特征切换、跨窗口探索和开发段获选模型组合，并保存触发依据。方向调整使用开发段平均命中，平分时比较标准差。有效参数空间有限，穷尽会如实停止，不通过重复配置制造尝试数量。

### 3. 独立滚动验证

先设置历史总期数、选号数量、开发期、保留期、训练窗；保存计划后逐期滚动比较固定方法清单，先冻结一个获选方案，再验证保留段。结果展示完整候选、训练截止、命中0至k分布、平均命中、至少命中各数量的分子分母及区间。

历史时间保留验证不等于可信远端前瞻认证；反复观察保留段后重开实验会带来多重比较。

### 4. 跨实验档案复用

严格按数据快照、选号数量、开发锚点、训练截止和实现版本区分条件，相同条件复用已成功计算，分别统计实际训练和档案复用。保留失败、取消和实验继承关系，可导出全部记录。复用结果不算新独立样本。

## 推荐操作流程

1. 打开数据中心，确认官方有效数据及截止期。
2. 在走势研究中观察多窗口指标，形成明确方法条件。
3. 进入自动研究中心，新建验证优先研究并预设预算。
4. 在“方法覆盖”和“研究方向与特征”查看实际执行情况。
5. 使用“独立滚动验证”比较固定方法与特征组，查看逐期结果和样本限制。
6. 保存或导出结果；满足条件时再在正式冻结流程中记录候选。

旧实验继续时保留原协议；需要升级搜索时使用“用旧实验参数新建去重搜索”，保留原记录。升级前请备份数据目录。运行中可切页或取消；底层训练可能在折次边界才退出，按钮反馈不等于训练立即结束。

## CPU与GPU

自动搜索支持有上限的CPU多进程，限制数值库内部线程以控制嵌套并行。多标签岭回归和LightGBM有OpenCL路径，其他部分仍由CPU完成；GPU占用高不代表更快或更准确。独立验证使用后台进程，保持界面响应。请勿把历史碰撞达到全匹配当作下一期保证。

## 实测结果

- 源码测试113项通过；Windows发布包研究、匹配、取消、独立验证、验证取消各10次，GPU路径1次。
- 中文含空格路径解压后，研究与独立验证运行通过，EXE和来源指纹一致。
- 预设144次搜索首次实际计算144条、失败0；相同条件第二实验144条全部复用、重训0。
- 300期片段，开发10期、保留30期、k=4、训练窗80/160，共28个方案完成。获选方案保留段平均命中1.0667，公平期望1，随机参考1.0333。
- 保留段命中0/1/2/3/4分布为6/17/6/1/0；相对公平期望95%区间[-0.1667,0.3000]，跨0，**未证明稳定优势**。

## 已知限制

启动及首次绘制心跳最大延迟仍约526—581ms，尚未全部达到低于500ms目标。干净Win10、多日运行、完整大规模压力矩阵仍需继续验收。可信远端前瞻认证、DeepSeek真实API辅助学习尚未完成本轮实际接入验收，不应理解为已经可用。版本保持preview。
